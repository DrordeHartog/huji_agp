# F0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployable page with Start button, video/canvas, status line, and stub modules that satisfy the spec's interfaces — so partners can build F1 and F2 in parallel.

**Architecture:** Static `index.html` loads `src/main.js` as an ES module. `main.js` wires five modules (`audio`, `camera`, `hands`, `overlay`, `control`) in a `requestAnimationFrame` loop. In F0, every module except `control.js` is a stub with the final signature.

**Tech Stack:** HTML, CSS, vanilla JS ES modules, Node 24 built-in `node:test` for the pure `control.js` only. No build step.

**Spec:** `docs/superpowers/specs/2026-10-13-hand-theremin-design.md`

## Global Constraints

- Browser only: no server, backend, database, API keys.
- No build step; plain ES modules.
- All asset URLs **relative** (`src/main.js`, not `/src/main.js`) — Pages serves under `/huji_agp_lab_1/`.
- Published from `main` via GitHub Pages at `https://drordehartog.github.io/huji_agp_lab_1/`.
- Camera + AudioContext started only inside the Start click handler.

## Review Focus

1. Opened via `file://` (double-click) → ES modules are blocked silently; user should see a message telling them to use a local server. Covered in Task 1 (inline check in `index.html`).
2. Start clicked twice → must not start two loops / two cameras. Covered in Task 1 (button disabled on click).
3. A module throws during startup (camera denied, MediaPipe load fails later in F2) → status line shows the error message, button re-enabled. Covered in Task 1 (`try/catch` in `main.js`).
4. Page served under a subpath → relative URLs. Covered in Task 2 (live URL check).
5. `handToSound([])` (no hand) → volume 0, never `undefined`/`NaN`. Covered in Task 1 test.

- [ ] **Step 3: Write `src/control.js`**

```js
// Pure mapping from detected hands to sound parameters.
// F4 (Partner A) owns handToFrequency; F5 (Partner B) owns handToVolume.

const BASE_FREQUENCY = 440; // A4

export function handToFrequency(hand) {
  return BASE_FREQUENCY;
}

export function handToVolume(hand) {
  return 0.3;
}

export function handToSound(hands) {
  if (hands.length === 0) return { volume: 0, frequency: BASE_FREQUENCY };
  const hand = hands[0];
  return { volume: handToVolume(hand), frequency: handToFrequency(hand) };
}
```

- [ ] **Step 6: Write `src/main.js`**

```js
import { createAudio } from "./audio.js";
import { startCamera } from "./camera.js";
import { createHandTracker } from "./hands.js";
import { drawFrame } from "./overlay.js";
import { handToSound } from "./control.js";

const startButton = document.getElementById("start");
const video = document.getElementById("video");
const canvas = document.getElementById("canvas");
const status = document.getElementById("status");
const ctx = canvas.getContext("2d");

function setStatus(text) {
  status.textContent = text;
}

async function start() {
  startButton.disabled = true;
  setStatus("Starting…");
  try {
    const audio = createAudio();
    await audio.start();
    await startCamera(video);
    const tracker = await createHandTracker();
    startButton.hidden = true;

    function frame(now) {
      const hands = tracker.detect(video, now);
      drawFrame(ctx, video, hands);
      const { volume, frequency } = handToSound(hands);
      audio.setVolume(volume);
      audio.setFrequency(frequency);
      setStatus(hands.length ? `Hand detected — playing ${Math.round(frequency)} Hz` : "No hand");
      requestAnimationFrame(frame);
    }
    requestAnimationFrame(frame);
  } catch (err) {
    setStatus(`Error: ${err.message}`);
    startButton.disabled = false;
  }
}

startButton.addEventListener("click", start);
setStatus("Press Start, then show your hand to the camera.");
```
