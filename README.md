# huji_agp

Agentic Programming (HUJI CS) — weekly lab sessions.
Each `lab_#` folder is a git submodule pointing to its own private repo `huji_agp_lab_#`.

Clone everything:

    git clone --recurse-submodules git@github.com:DrordeHartog/huji_agp.git

Pull latest of all labs:

    git submodule update --remote --merge
